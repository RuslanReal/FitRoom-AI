
# FitRoom AI

Intelligent Fashion Marketplace with AI Stylist and Virtual Try-On.

## Description

FitRoom AI is an Android fashion marketplace where customers can browse clothing from different sellers, receive personalized outfit recommendations, and virtually try on clothes using AI.

## Main Features

- User registration and authentication
- Clothing catalog and product search
- Shopping cart and orders
- Seller dashboard
- AI-powered personal stylist
- AI virtual try-on

## Technologies

- Kotlin + Jetpack Compose
- Python + FastAPI
- PostgreSQL + Room
- Rule-based AI expert system
- Cloud AI virtual try-on API

## Project Structure

- android-app: Android application
- backend: REST API and business logic
- ai-stylist: AI expert system
- ai-tryon: Virtual try-on integration
- docs: Project documentation
